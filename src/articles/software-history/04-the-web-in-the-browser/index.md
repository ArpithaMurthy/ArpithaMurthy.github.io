# The Web Puts Software Within Reach

The internet and the Web are not the same invention. The internet connects networks and computers. The Web is one way of using that connected infrastructure: pages and resources linked so people can move from one to another.

That distinction matters because the Web's breakthrough was not simply putting documents online. It made a shared, open space where a link could take you somewhere new, regardless of which computer held the page.

## The Web begins as a way to connect information

At CERN, Tim Berners-Lee proposed a system for sharing information across a changing organization. In 1989 he wrote a proposal; by 1990 he had developed the first browser-editor and web server. The first website described the World Wide Web project itself.

The Web combined a few simple ideas: addresses for resources, a way to request them, a format for documents, and links between documents. The early technologies—URLs, HTTP, and HTML—were deliberately useful across different kinds of computers.

## Browsers make the network feel like a place

As browsers became easier to use and more widely available, people could explore the Web without knowing where a file lived or how to connect to its server. The browser became a new kind of software front door. A link could lead to a research page, a shop, a community, or a service.

The first web pages were mostly documents. As networks, browsers, and server-side tools improved, developers began building interactive sites backed by databases: search, email, shopping, maps, and social spaces. The software did not have to be installed in full on each user's computer; much of it could run on a server and be reached through a browser.

## The app moves across machines

This changed how software was delivered. A company could update its service in one place instead of shipping a new disk to every user. A person could reach the same account from different computers. At the same time, a useful service now depended on networks, servers, identity, security, and keeping data available.

The Web did not make the desktop disappear. It made the network itself part of the application. Later, smartphones would take that networked software out of the study and office and into people's pockets.

What changes when the internet is not a place you visit at a computer, but something you carry all day?
